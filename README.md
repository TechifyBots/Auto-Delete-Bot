## 🌸 Overview

**Auto Delete Bot** helps keep your Telegram chats clean and organized with **automatic message deletion**, **custom timers**, and **easy-to-use admin controls**.

Give your groups and channels a cleaner experience with **effortless message management**.


> *✨ Keep your chats clean, clutter-free, and organized — automatically!.*

#### 🤔 Why Choose This Project?

- ⚡ **Automated Cleanup:** Automatically deletes messages without manual effort.
- ⏱️ **Custom Timers:** Set deletion delays according to your needs.
- ⚙️ **Easy Controls:** Manage settings through a simple interactive panel.
- 🛡️ **Admin Control:** Keep message cleanup under administrator control.

#### 🔄 How It Works

1. 📥 **Message Detection:** Monitors incoming messages in groups and channels.
2. ⚙️ **Settings Check:** Checks whether auto-delete is enabled.
3. ⏱️ **Timer Scheduling:** Schedules messages for deletion using your configured timer.
4. 🗑️ **Automatic Deletion:** Deletes messages once their timer expires.

---

## ✨ Features

- ⚡ **Automatic Message Deletion** – Deletes messages after a configured delay.
- ⏱️ **Custom Deletion Timers** – Set delays in seconds, minutes, or hours.
- 👥 **Group Support** – Supports groups and supergroups.
- 📢 **Channel Support** – Automatically cleans up channel messages.
- ⚙️ **Interactive Settings** – Manage settings with inline buttons.
- 🔘 **Quick Toggle Controls** – Enable or disable auto-delete easily.
- 🔒 **Admin Permissions** – Restricts settings management to administrators.
- 💾 **MongoDB Storage** – Stores chat settings and scheduled messages.
- 🔄 **Deletion Recovery** – Restores pending deletion jobs after a restart.
- 📊 **Bot Statistics** – View bot usage statistics.
- 📣 **Owner Broadcast** – Broadcast messages to bot users.
- ⏳ **Flexible Time Limit** – Supports deletion delays up to one hour.

|:---------|:------------|
| `API_ID` | Telegram API ID |

## 🤖 Commands

```
start - Start the bot.
help - Get the bot usage guide.
settings - Open the auto-delete settings panel.
setdelete - Set a custom deletion timer.
deleteon - Enable automatic message deletion.
deleteoff - Disable automatic message deletion.
broadcast - Broadcast messages to all bot users (Owner only).
```
